Primeros Pasos en StockPro

Guía rápida para empezar a usar la app

StockPro te permite armar un catálogo de referencia (el padrón de artículos), cargar tu inventario relevando productos por código de barras, y consultar o exportar esa información cuando quieras. Esta guía cubre las tres tareas más comunes al empezar: importar el padrón, agregar productos y buscar artículos.

Todas las opciones mencionadas se encuentran en el menú principal (ícono ☰, arriba a la derecha del Dashboard).

1Importar el Padrón de Artículos

El padrón es tu catálogo de referencia: nombre, marca, unidad y precio de cada producto conocido. Se usa para autocompletar datos cuando escaneás un código al cargar inventario. No es tu inventario — es solo el listado de consulta.

Cómo importar: Menú → Importar Padrón Artículos → elegí el archivo (botones "JSON" o "CSV / Excel").

Importante sobre Excel: el botón dice "CSV / Excel" pero la app solo lee archivos .csv de texto, no libros de Excel (.xlsx) directamente. Si tu padrón está en Excel o Google Sheets, guardalo primero como CSV (delimitado por comas) desde el propio programa (Archivo → Guardar como → CSV) y luego importá ese archivo.
Importar reemplaza el padrón anterior: cada vez que importás un archivo, el padrón completo se borra y se reemplaza por el nuevo contenido. No se combinan ni se suman artículos. Esto no afecta tu inventario ya relevado (eso es independiente), pero si querés conservar el padrón anterior, exportalo o guardá una copia del archivo antes de reemplazarlo.

Formato CSV

  • Separador: coma , o punto y coma ; — se detecta automáticamente.
  • Encabezado: opcional. Si no hay encabezado reconocible, las columnas se leen por posición: código de barras, nombre, marca, unidad, precio, descripción.
  • Encabezados en español o inglés, mayúsculas o minúsculas — se detectan automáticamente (ver tabla).
  • Campos entre comillas (para valores con comas) y archivos exportados desde Excel con BOM UTF-8 son compatibles.
  • El precio acepta formato argentino (1.500,00), estadounidense (1500.00) o simple (1500).
  • El código de barras es obligatorio en cada fila; las filas sin código se descartan.

Ejemplo de CSV válido:

barCode,name,tradeMark,unit,price,description
7790001234567,Yerba Mate,La Merced,Paquete,1500,500g
7790009876543,Aceite Girasol,Cocinero,Litro,2200,1L

Formato JSON

Un array de objetos. Las claves también admiten variantes en mayúsculas/minúsculas (barCode, BARCODE, Barcode, etc.). Solo barCode es obligatorio.

[
  {
    "barCode": "7790001234567",
    "name": "Yerba Mate",
    "tradeMark": "La Merced",
    "unit": "Paquete",
    "price": 1500,

  },
  {
    "barCode": "7790009876543",
    "name": "Aceite Girasol",

2Agregar un Nuevo Producto/Item

Desde el Dashboard, tocá Agregar (botón +), o el botón + desde la lista de artículos.

  1. Escribí o escaneá el código de barras (ícono de escáner en el campo). Si el código ya existe en el padrón importado, los campos se completan solos.
  2. Si preferís buscarlo manualmente, usá el botón Buscar en Padrón de Artículos para elegirlo de una lista.
  3. Completá o ajustá: Nombre (obligatorio), Marca, Precio (obligatorio), Cantidad, Cantidad por bulto, Unidad (desplegable: Unidad, Kg, Gramos, Litro, Mililitro, Caja, Paquete, Docena, Par, Metro, Rollo) y Descripción adicional.
  4. Guardá con el botón ✓ (abajo a la derecha).
El plan gratuito tiene un límite de artículos cargados. Al acercarte al límite, la app te avisa y ofrece pasar a StockPro Premium para cargar sin restricciones.

3Buscar un Producto en el Padrón

Menú → Consulta Artículos.

  • Buscá escribiendo nombre, marca o código, o tocá el ícono de escáner para buscar por código de barras.
  • Cada resultado muestra nombre, marca, código, unidad y precio.
  • Esta misma búsqueda está disponible dentro del formulario de "Agregar Producto", para elegir un artículo del padrón sin escanear.

4Otros pasos recomendados

  • Exportar Datos (Menú → Exportar Datos): tu inventario relevado se guarda solo en el dispositivo, sin copia en la nube. Exportalo periódicamente para tener un respaldo.
  • Importar Datos (Menú → Importar Datos): restaura un relevamiento previamente exportado — a diferencia del padrón, esto es tu inventario cargado, no el catálogo de referencia.
  • Resetear Artículos (Menú → Resetear Artículos): vacía el inventario relevado. Es una acción destructiva, usala solo si querés empezar de cero.
  • Gratis vs. Premium: el plan gratuito incluye publicidad y un límite de artículos; Premium elimina la publicidad y quita ese límite.
  • Ayuda dentro de la app (Menú → Ayuda): preguntas frecuentes y contacto directo con soporte.
